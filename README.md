# Agenda de Contatos

Aplicação de linha de comando desenvolvida em Python para gerenciar uma agenda de contatos.

Este projeto foi desenvolvido como desafio prático do módulo **Introdução ao Python**, da Rocketseat, com o objetivo de reforçar conceitos fundamentais da linguagem por meio de uma aplicação interativa no terminal.

## Funcionalidades

- Adicionar contatos com nome, telefone e e-mail;
- Listar todos os contatos cadastrados;
- Editar um contato existente;
- Excluir um contato;
- Marcar ou desmarcar um contato como favorito;
- Visualizar os contatos favoritos;
- Sair da aplicação pelo menu principal.

## Tecnologias utilizadas

- Python 3

## Como usar

Ao iniciar a aplicação, um menu será exibido no terminal. Digite o número correspondente à operação desejada:

1. Adicionar contato
2. Editar contato
3. Excluir contato
4. Favoritar ou desfavoritar contato
5. Listar contatos
6. Sair

## Observações

Os contatos são armazenados apenas durante a execução do programa. Ao encerrar a aplicação, os dados não são persistidos em um arquivo ou banco de dados.
